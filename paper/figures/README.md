# Figure assets

The LaTeX source expects these files:

- `fig1_overview.pdf`: full-width problem and method overview.
- `fig2_rtg.pdf`: optional single-column RTG example for the Method section.
- `fig3_transfer_heatmap.pdf`: full-width directed transfer matrix.
- `fig4_drc_prediction.pdf`: single-column prospective prediction plot.
- `fig5_capability_flow.pdf`: full-width capability-flow and pass@k figure.

Use vector PDF for diagrams and plots. Use PNG only for genuinely raster
content, at 300 dpi or higher at final print size. Crop external whitespace and
ensure that all text remains at least 7--8 pt after the figure is scaled to its
LaTeX width. Do not encode meaning by color alone.
