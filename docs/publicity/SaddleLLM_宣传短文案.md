## 公众号摘要

SaddleLLM 2.40 提供统一的命令行和 Python 部署入口，连接模型训练与文本服务。本文介绍自有 W8A16 推理优化、可选 vLLM 后端，以及完整 Qwen3-8B 的实测结果与适用边界。

## 朋友圈短文案

我们最近把 SaddleLLM 的推理部署入口进一步简化了。安装好环境、准备好模型后，用 saddlellm serve 就能启动 OpenAI 兼容文本服务，也能从 Python import 启动。底层可以选择自有原生优化路线，或在兼容环境中使用 vLLM。文章里整理了完整 Qwen3-8B 的实测、部署步骤和功能边界，欢迎做模型训练与应用部署的朋友交流试用。

## 性能介绍短文案

完整 Qwen3-8B，NVIDIA L20，自有 W8A16，非流式贪心补全，八请求固定微批：本次有限测试观测到总输出吞吐约 252.8 token/s，相比同路线逐请求执行的 32.4 token/s 约为 7.79 倍。测试使用同一 10-token 短提示，每请求输出 64 token，缓存关闭，每配置 16 个计时样本。该结果不是单用户速度；微批与串行输出文本有差异，尚待质量验收，不能称为无损提升或跨引擎排名。
